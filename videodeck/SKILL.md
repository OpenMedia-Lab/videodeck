# videodeck

Make a video that teaches the source's actual mechanism. Preserve its terms,
formulas, examples and caveats; choose pacing and visual language for this content.
HyperFrames is the default renderer. Voice tools remain replaceable; caption-cli
prepares local evidence for the current agent or subagents, without a model API.

## Resolve the task

Read [intake](references/intake.md). Reuse explicit task answers and established
standing preferences. Ask only consequential missing choices through the host's
interactive question tool and wait for an actual answer. Preselection, silence,
timeout and announcing assumptions do not resolve them. While waiting, read full
sources and inspect capabilities; pause work dependent on unresolved choices.

Persist answers/provenance, source pointers and accepted versions in the project.
For revisions, preserve locked content and change only the authorized scope.

## Produce and review

1. Read [storyboard](references/storyboard.md). Establish the explanatory thread
   and rough shots before detailed styling. Each shot connects source, narration,
   action and the next shot. A topic without sources first needs an agreed content
   creation scope.
2. If narration or music is wanted, read [audio](references/audio.md). Present
   actual auditions for a new voice; reuse an accepted voice. Generate a coherent
   complete master track, then refine the timeline from its real duration, pauses
   and acoustic anchors. Keep display text separate from pronunciation aliases.
   With no soundtrack, use narrative actions to establish timing.
3. Read [art direction](references/art-direction.md). Show coded key static frames
   and an independently designed cover before producing a new full visual
   direction. Obtain the user's choice; reuse accepted directions. Add a short
   motion sample when needed. Keep essential math readable and transitions causal.
4. Read [HyperFrames](references/hyperframes.md). Check installed CLI capabilities,
   use a pinned reproducible runtime and one deterministic, seekable timeline.
   Preserve the complete master audio across visual cuts. Render the actual MP4.
5. Read [review](references/review.md). Prepare full-range caption-cli evidence;
   actually inspect the assigned evidence and densely examine suspect transitions.
   Check source fidelity, math, subtitles, first/last sounds and encoding. Record
   coverage and capability limits. Tool success, forced alignment and contact
   sheets alone cannot establish semantic or listening quality. Repair affected
   artifacts and review them again before showing the film to the user.
6. Present the complete film for human review, then apply authorized feedback.
   Deliver the versioned video, cover, captions, editable sources and review record
   locally, or continue to the requested publication route.

## Publication is a separate decision

Read [publishing](references/publishing.md) only for platform delivery. Display
the **full final title, description, category, tags and visibility for each video**
through the interactive question tool and wait for explicit confirmation before
submission. General intent to publish does not replace this final metadata gate.
Reuse confirmation of the same version; changed metadata needs a new answer.
Read back actual text, paragraph breaks, media, collection order and platform
state after submission. Reconcile uncertain outcomes before retrying.
